# 🍃 Leaf – Free PDF Editor

**[Try me](https://sreekuttan28.github.io/Leaf-pdf-editor/)**

Leaf is a free PDF editor that runs in your browser. No sign-in, no cost, and your files never leave your device.

Made by **Mokuttan Labs**.

---

## What you can do

- **Edit text** – tap a line in your PDF and retype it
- **Scan text** – make scanned PDFs and photos of documents editable
- **Add text, images, signature and stamps** (✓ ✗ date)
- **Highlight, draw, box and whiteout**
- **Delete pages, undo/redo, duplicate**
- **Dark and light mode** – use the sun/moon switch at the top
- **Works offline** and can be installed like an app

---

## How to use

1. Tap **Try me** above, then tap **Open a PDF** and choose your file.
2. Pick a tool from the toolbar and tap or drag on the page.
3. For a scanned PDF, tap **Scan text** first, then **Edit text**.
4. Tap **Save PDF**, type a file name, and save.

Need help inside the app? Tap the **?** button at the end of the toolbar.

---

## Install on your phone

- **Android (Chrome):** menu ⋮ → **Add to Home screen**, or tap **Install app** in Leaf.
- **iPhone (Safari):** tap **Share** → **Add to Home Screen**.

---

## Built with

- HTML, CSS and JavaScript (no framework)
- [pdf.js](https://mozilla.github.io/pdf.js/) – shows the PDF
- [pdf-lib](https://pdf-lib.js.org/) – saves the edited PDF
- [Tesseract.js](https://tesseract.projectnaptha.com/) – reads scanned pages (OCR)
- Service worker and web manifest – offline use and install

---

## Good to know

- Edited text is hidden, not deleted, so don't use Leaf to hide secret information.
- Scan text works best on clear, straight scans. Check the result after scanning.
- Scan text and install need the online (hosted) version, not a file opened from storage.
